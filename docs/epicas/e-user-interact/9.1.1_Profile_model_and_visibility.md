# 9.1.1 --- Modelo de Perfil y Matriz de Visibilidad

  
## Tablas

### users
Dedicada a la cuenta, datos personales y autenticación.

- `id` → `uuid` **PK** `DEFAULT gen_random_uuid()`
- `email` → `citext` **UNIQUE NOT NULL**
- `created_at` → `timestamptz` **NOT NULL** `DEFAULT now()`
- `updated_at` → `timestamptz` **NOT NULL** `DEFAULT now()`

### user_profiles
Lo que va en el perfil de usuario.

- `user_id` → `uuid` **PK + FK** → `users(id)` `ON DELETE CASCADE`
- `username` (alias) → `varchar(30)` **UNIQUE NOT NULL**
- `avatar_url` → `text` (NULL)
- `bio` → `varchar(280)` (NULL)

### posts

- `id` → `uuid` **PK** `DEFAULT gen_random_uuid()`
- `author_id` → `uuid` **FK NOT NULL** → `users(id)` `ON DELETE CASCADE`
- `content` → `text` **NOT NULL**
- `image_url` → `text` (NULL)
- `created_at` → `timestamptz` **NOT NULL** `DEFAULT now()`
- `updated_at` → `timestamptz` **NOT NULL** `DEFAULT now()`

### friendships
- `id` → `uuid` **PK** `DEFAULT gen_random_uuid()`
- `requester_id` → `uuid` **FK NOT NULL** → `users(id)` `ON DELETE CASCADE`
- `addressee_id` → `uuid` **FK NOT NULL** → `users(id)` `ON DELETE CASCADE`
- `status` → `friendship_status` (ENUM) NOT NULL
    valores:  `pending`, `accepted`, `rejected`
- `created_at` → `timestamptz` **NOT NULL** `DEFAULT now()`
- `updated_at` → `timestamptz` **NOT NULL** `DEFAULT now()`

## Reglas Generales

- Toda la aplicación requiere autenticación para acceder a perfiles.
- Los visitantes sin cuenta solo pueden acceder a las páginas de `login` y `registro`.
- El contenido de los posts es privado y solo visible para amigos y el propietario.
- Los datos personales (como el email) solo son visibles para el propietario.
- `friendship_status` es un campo relativo al usuario visitante del perfil, no al perfil.
- `friend_list` es un recurso derivado que no un campo, y se crea a partir de los `friendships` con `status == accepted`.
- `online_status` dato no persistente.
- `user_id` se expone únicamente a usuarios autenticados como identificador interno en la API y no se muestra en la interfaz de usuario.
